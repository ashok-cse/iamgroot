# IamGroot

[English](../README.md) · [中文](README.zh.md) · [हिन्दी](README.hi.md) · **Español** · [Français](README.fr.md) · [العربية](README.ar.md) · [বাংলা](README.bn.md) · [Português](README.pt.md) · [Русский](README.ru.md) · [اردو](README.ur.md)

**Tu buscador de empleo personal.**

Buscar trabajo lleva mucho tiempo. IamGroot hace por ti las partes lentas y aburridas. Es un ayudante que funciona dentro de herramientas de chat con IA como Claude Code, Codex, ChatGPT, Gemini y Cursor. Sirve para cualquier tipo de trabajo, en cualquier país.

## Qué hace

1. **Te conoce.** Lee tu currículum y te hace algunas preguntas, como dónde quieres trabajar y cuándo puedes empezar.
2. **Prepara un currículum limpio.** Crea un currículum de una página que los programas de selección pueden leer sin errores.
3. **Busca empleos.** Revisa las páginas de empleo de muchas empresas y se queda con los trabajos que encajan contigo.
4. **Se postula por ti.** Rellena los formularios con tus datos y los envía. Si tu herramienta de IA no puede usar un navegador, escribe las respuestas y tú las envías.
5. **Lleva una lista.** Cada empleo queda en una lista, así siempre sabes dónde te postulaste y qué pasó.
6. **Aprende.** Recuerda tus respuestas, así no te hace la misma pregunta dos veces.

## Cómo empezar

Necesitas una herramienta de chat con IA. Para usar todas las funciones también necesitas Python, un programa gratuito, en tu computadora.

1. Consigue IamGroot. Ejecuta este comando, o descarga este proyecto y ábrelo en tu herramienta de IA:

   ```bash
   npx skills add ashok-cse/iamgroot
   ```

2. Dile a tu herramienta de IA: **"You are IamGroot. Onboard me."** (significa: eres IamGroot, empieza a conocerme).
3. Dale tu currículum y responde sus preguntas.
4. Pídele que busque empleos y se postule.

## Tu información se queda contigo

Todo lo que trata de ti se guarda en una carpeta llamada `profile/` en tu propia computadora. Nunca se añade a este proyecto ni se comparte.

## Lo que nunca hará

- Inventar habilidades, empleos o respuestas. Si solo tú sabes la respuesta, te la pregunta.
- Crear cuentas, escribir contraseñas o saltarse las pruebas de «No soy un robot».
- Postularse a trabajos que no encajan contigo solo para llegar a un número mayor.
